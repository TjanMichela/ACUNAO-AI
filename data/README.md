## Data Structure

The `data` folder is organized as follows:

```
data/
│
├── 1_references/
│   ├── files        # References used  
│   ├── list_potential.md
│   ├── README.md
│
└── 2_test_data/
    ├── ips-revised-handbook-2022-2023.pdf       # Documents used for testing  
    ├── msds_admissions.pdf   
    ├── msds_financing.pdf
    ├── README.md
```

### 1_references

- `data/1_references/files`: Contains reference sources files.   
- `data/1_references/list_potential.md`: Contains the list of current and potential reference sources.  
- `data/1_references/README.md`: Readme file for the folder.  

### 2_test_data

The folder contains the documents used to test the performance of the ACUNAO AI Assistant.
